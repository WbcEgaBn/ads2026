WINE DATA ANALYSIS AND BALANCED MODEL TRAINING REPORT

1. Data and exploratory visuals
Combined_Wine.csv contains 6,497 rows, 14 variables, no missing values, and
1,177 exact duplicates. The 21 exploratory charts retain all source rows.
Alcohol correlates with quality at r = 0.44; density at r = -0.31 and
volatile acidity at r = -0.27. These associations are not causal findings.

2. Shared implementation and scaling
Both training implementations now live in preprocessing.py.
model_training.py and train_wine_neural_network.py are compatibility entry
points. Both models use the same chemical features and binary wine encoding.
StandardScaler learns feature means and variances from each original training
partition before resampling. Validation rows receive that training partition's
transformation. Reserved test rows are not transformed or evaluated.

3. Equal training counts for Low, Medium, and High
The shared balance_training_indices helper implements the original KNN policy:
retain Medium training rows, then sample Low and High with replacement to match
the Medium count. Resampling happens only after data is partitioned.
Every inner neural network fit, outer fold refit, and final fit uses exactly
equal class totals. Each epoch traverses that balanced dataset once.
The final neural network fit uses 3,665 Low, 3,665 Medium, and 3,665 High samples
per epoch (10,995 samples total, including repeated minority-class rows).
Validation folds keep their original class proportions.
training_balance.csv in each model directory records counts for every fit.

4. Training and validation recipes
KNN retains the original 6,497 raw rows, stratified 80/20 split, 10-fold
validation, distance weighting, Manhattan distance, and odd K values 1–21.
Scaling is now fitted inside each fold. Its 1,300 test rows are not evaluated.
Best K: 1; mean validation macro F1: 0.6003.

The neural network retains numerical quality as its target; quality_class is
used for balancing and excluded from input features. Exact duplicates are
removed, leaving 5,320 rows. The original 532-row test partition is reserved.
Grouped 5-fold validation uses 4,788 development rows; identical inputs stay
together. An inner grouped validation split selects the epoch count, then each
network refits on its full outer training fold before validation scoring.
Selected architecture: (64, 32); final training: 5 epochs.
Mean validation MAE: 0.638 +/- 0.019 quality points.
Mean exact rounded-score accuracy: 47.5% +/- 1.5%.
Mean within-one-point accuracy: 93.5% +/- 0.8%.
The final scaler is fitted on the original 4,788 development rows; the target
mean is calculated from the balanced training samples.

5. Artifacts and verification
Regenerated the neural network model, validation predictions, six model charts,
and KNN validation outputs and charts. training_class_balance.png shows counts
before and after resampling. Full results are in each model directory's report.md.
Verified equal counts in all 31 neural network/baseline training records and all
10 KNN folds; sampled rows stay inside their training partitions. Confirmed
validation coverage, reserved-row exclusion, and saved scaler means/variances.
No test-set predictions or test-set model evaluation were performed.

6. Limitations
Balancing gives rare classes more training influence and changes the resulting
metrics. Model selection uses these validation results, so selected-model scores
may be optimistic. KNN and the neural network use different targets and split
recipes; their scores are not directly comparable. Earlier repository outputs
evaluated the neural network's reserved partition, so it is not historically
unseen. This workflow does not evaluate it.

Regenerate both workflows:
python3 preprocessing.py

Run only the neural network:
python3 preprocessing.py --model neural-network --folds 5
