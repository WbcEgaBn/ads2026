2. Shared implementation and scaling
Both training implementations live in preprocessing.py.
model_training.py and train_wine_neural_network.py are compatibility entry
points. Both models use the same chemical features and binary wine encoding.
StandardScaler learns feature means and variances from each original training
partition before resampling. Validation rows receive that training partition's
transformation. Reserved test rows are not transformed or evaluated.

3. Equal training counts for Low, Medium, and High
The shared balance_training_indices helper retains Medium training rows, then
samples Low and High with replacement to match the Medium count. Resampling
happens only after data is partitioned. Every inner neural network fit, outer
fold refit, and final fit uses exactly equal class totals. Each epoch traverses
that balanced dataset once. The final fit uses 3,665 Low, 3,665 Medium,
and 3,665 High samples per epoch (10,995 total, including repeated rows).
Validation folds keep their original class proportions.
training_balance.csv in each model directory records counts for every fit.

4. Training and validation recipes
KNN uses all 5,320 wine2.csv rows, a stratified 80/20 split, 10-fold validation,
distance weighting, Manhattan distance, and odd K values 1–21.
Scaling is fitted inside each fold. Its 1,064 test rows are not evaluated.
Best K: 3; mean validation macro F1: 0.5324.

The neural network retains numerical quality as its target; quality_class is
used for balancing and excluded from input features. Deduplication removes
0 rows, leaving 5,320. A 532-row test partition is reserved.
Grouped 5-fold validation uses 4,788 development rows; identical inputs stay
together. An inner grouped validation split selects the epoch count, then each
network refits on its full outer training fold before validation scoring.
Selected architecture: (64, 32); final training: 5 epochs.
Mean validation MAE: 0.638 +/- 0.019 quality points.
Mean exact rounded-score accuracy: 47.5% +/- 1.5%.
Mean within-one-point accuracy: 93.5% +/- 0.8%.
The final scaler is fitted on the original 4,788 development rows; the target
mean is calculated from the balanced training samples.

6. Limitations
Balancing gives rare classes more training influence and changes the resulting
metrics. Model selection uses these validation results, so selected-model scores
may be optimistic. KNN and the neural network use different targets and split
recipes; their scores are not directly comparable. Earlier repository outputs
evaluated the neural network's reserved partition, so it is not historically
unseen. This workflow does not evaluate it.

Regenerate charts and both workflows:
python3 wine_visuals.py
python3 preprocessing.py

Run only the neural network:
python3 preprocessing.py --model neural-network --folds 5
